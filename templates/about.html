About SysRecover
SysRecover - OS-DBMS Simulation Platform

SysRecover is an interactive educational platform that demonstrates the interaction between operating system processes, memory management, and database transaction systems.

Features
  • CPU Scheduling: FCFS, SJF, SRTF, Round Robin, Priority Scheduling
  • Memory Management: FIFO, LRU, Optimal page replacement
  • Transaction Management: ACID properties demonstration
  • Lock-based Concurrency Control: Shared/Exclusive locks, Two-Phase Locking
  • Deadlock Detection and Recovery: Wait-for graph analysis
  • Database Crash Recovery: UNDO/REDO with write-ahead logging
  • Smart Diagnostics: Rule-based performance analysis
Technology Stack
  • Backend: Python 3, Flask, SQLAlchemy, SQLite
  • Frontend: HTML5, Bootstrap 5, Vanilla JavaScript, Chart.js
Educational Purpose

This application is designed for educational purposes to help students understand the complex interactions between OS and DBMS mechanisms. All operations are simulated and do not affect the host system.
